Installer NOVA Tree

Deux étapes, une seule fois : 1. ajouter l'application à votre écran d'accueil, 2. installer le lanceur, qui lit votre réseau sur MWR et met l'application à jour.

1. L'application sur l'écran d'accueil

  1. Ouvrez dans Safari.
  2. Touchez Partager (le carré avec la flèche), puis Sur l'écran d'accueil, puis Ajouter.

L'icône NOVA Tree ouvre l'application dans Safari : c'est voulu, pour qu'elle retrouve les données envoyées par le lanceur.

2. Le lanceur : raccourci iPhone recommandé

Le plus simple : un toucher pour l'installer, puis il apparaît dans le menu Partager de Safari.

  1. Ajouter le raccourci « NOVA Tree » puis touchez Ajouter le raccourci.
  2. Une seule fois, autorisez les scripts : Réglages → Apps → Raccourcis → Avancé → activez Autoriser l'exécution de scripts.

Utilisation

Dans NOVA Tree, touchez Mettre à jour → sur la page MWR, touchez Partager → NOVA Tree. Au premier usage, iOS demande l'autorisation pour mwrlife.com : choisissez Toujours autoriser.

Le lien du raccourci n'est pas encore disponible. En attendant, utilisez le favori ci-dessous, ou demandez le lien à votre responsable d'équipe.

  1. Ouvrez dans Chrome.

2. Le lanceur : favori Chrome

  2. Sur cette page, touchez ⋮ puis l'étoile ☆ pour l'ajouter aux favoris.

Sur la page MWR, tapez NOVA Tree dans la barre d'adresse et touchez la suggestion NOVA Tree marquée d'une étoile.

  1. Affichez la barre de favoris (⌘ ⇧ B sur Mac, Ctrl ⇧ B sur PC ; dans Safari : Présentation → Afficher la barre des favoris).
