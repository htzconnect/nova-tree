# NOVA Tree

Tableau de bord personnel d'équipe MWR Life (WebApp statique, GitHub Pages).

- Aucune donnée n'est stockée dans ce dépôt ni envoyée à un serveur : chaque utilisateur lit son propre réseau
  depuis sa session sur mwrlife.com (favori ou raccourci iPhone), et les données restent sur son appareil.
- Installation : ouvrir `installer.html` sur le site publié.
- Les fichiers `app.js`, `collect.js` et `index.html` sont générés par `build_webapp.py` (hors dépôt) ;
  les fichiers commençant par `_` sont les sources (non publiés par GitHub Pages).
